===================================================
AGX Dynamics ライセンスの取得とアクティベーション
===================================================

OperaSim-AGX の物理エンジンである AGX Dynamics for Unity を動かすには、ライセンスが必要です。この章では、次の 2 つの手順を説明します。

1. ベンダーへ評価版を申請する
2. シミュレータ PC でアクティベーションする

この 2 つは別々の手順です。評価版を申請しただけでは、アクティベーションは完了しません。

評価版（トライアル）の申請
----------------------------

AGX Dynamics for Unity の公式ページは `https://www.algoryx.se/agx-unity/ <https://www.algoryx.se/agx-unity/>`_ です。ページ内の "Free trial" から、評価版を申請できます。

申請の際は、このプロジェクトに必要な構成をベンダーに伝えます。次の情報をあらかじめ用意しておくと、スムーズです。

- 製品名：OperaSim-AGX（ハッカソンでの利用）
- 必要な製品：AGX Dynamics for Unity
- 必要なモジュール：Core、Particles、Granular、Terrain、Tracks
- 対象プラットフォーム：Windows
- 同梱バージョン：AGXUnity 5.1.1+6f490ac5（AGX Dynamics 2.38.0.1）
- 利用期間：ハッカソンの開催日程

フォームの必須項目や試用期間の長さは、ベンダーが決めています。このマニュアルでは確定した内容として扱いません。フォームで求められる情報（連絡先、所属、利用目的など）は、その都度入力してください。

.. warning::

   ライセンスファイルとアクティベーション用のパスワードは、認証情報です。リポジトリにコミットしたり、チャットに貼り付けたりしないでください。また、ライセンスを配布物に同梱して再配布することは、できないものとして扱ってください。

アクティベーションの種類
--------------------------

アクティベーションを行うと、シミュレータ PC に ``agx.lfx`` というファイルが生成されます。このファイルは **その PC のハードウェアに紐付いており** 、別の PC にコピーしても使えません。旧形式の ``agx.lic`` も、引き続き利用できます。

シミュレータの実行方法によって、手順が分かれます。

- **Unity Editor で Play する場合**：エディタの License Manager でアクティベーションします。
- **ビルド済みプレイヤー（配布バイナリを含む）を実行する場合**：スタンドアロン用のアクティベーションを行います。

エディタでのアクティベーション
--------------------------------

Unity Editor でプロジェクトを開いた状態で、次の手順を行います。

1. メニューの **AGXUnity > License > License Manager** を開きます。
2. まず、この PC で有効なライセンスがすでにないかを確認します。以前この PC でアクティベーション済みの場合は、再度アクティベーションせず、既存の ``.lfx`` を使ってください。同じライセンスをエディタとビルド済みプレイヤーの両方で使える場合があるため、不要なアクティベーションは繰り返さないようにします。
3. "Activate license" 欄に、 **License Id** と **Activation Password** を入力します。
4. **License File Directory** に ``Assets/AGXUnity/Plugins/x86_64`` を指定します。この欄は、プロジェクト内のフォルダを表示するだけのラベルで、直接入力はできません。クリックするとフォルダ選択ダイアログが開くので、そこから選びます。未設定の場合や、存在しないフォルダを指定した場合は、 ``Assets`` 直下に保存されます。このガイドでは、 ``Assets/AGXUnity/Plugins/x86_64`` を保存先とします。
5. **Activate** を押します。生成された ``agx.lfx`` が、指定したフォルダに保存されます。

ライセンスの状態（有効期限、モジュール構成）は、同じ License Manager のウィンドウで確認できます。必要なモジュールが含まれていることと、期限が切れていないことを、ここで確認してください。

.. note::

   同じ Windows PC でアクティベーションした ``.lfx`` は、ライセンスの条件が許す範囲で、エディタとビルド済みプレイヤーの両方で使えます。エディタ用とプレイヤー用に、別々のアクティベーション（ライセンス数）が必要になるとは限りません。利用条件、同時に使える数、再配布の可否は、ベンダーが発行した内容に従ってください。

スタンドアロン（ビルド済みプレイヤー）でのアクティベーション
------------------------------------------------------------

配布バイナリや、自分でビルドしたプレイヤーでは、エディタの License Manager は使えません。ベンダーが提供する次のどちらかのツールで、シミュレータ PC 上に ``agx.lfx`` を生成します。

- AGX Dynamics のインストールに付属する **AGX License Manager** （Windows 版、GUI あり）
- 公式のライセンスドキュメントで案内されている、スタンドアロン用のアクティベーションユーティリティ（テキストベースのコマンドラインツール）

公式の手順は、次のドキュメントを参照してください。

- `AGXUnity ドキュメント Licensing 節 <https://us.download.algoryx.se/AGXUnity/documentation/current/getting_started.html#licensing>`_
- `AGX Dynamics ユーザーマニュアル License System <https://www.algoryx.se/documentation/complete/agx/tags/latest/doc/UserManual/source/license_system.html>`_

どちらのツールも、手順の流れは共通です。シミュレータ PC をインターネットに接続した状態でツールを起動し、ベンダーから受け取ったライセンス ID とアクティベーション用パスワードを入力して、出力先を指定すると、 ``agx.lfx`` が生成されます。コマンドラインツールの正確な起動方法とオプションは、ベンダーの配布物に付属する ``--help`` などの公式の案内に従ってください。このマニュアルでは、実行ファイル名やオプションは示しません。

生成したら、次の 2 点を確認します。

- ``agx.lfx`` が有効であること（期限切れや失効になっていないこと）
- 必要なモジュール（Core、Particles、Granular、Terrain、Tracks）が含まれていること

生成したファイルは、 **プレイヤーの実行ファイルと同じフォルダか、その下のフォルダ** に置きます。

.. important::

   ライセンスの検索は、 **カレントディレクトリ** を起点に再帰的に行われます。 ``.lfx`` を先に探し、次に ``.lic`` を探します（実装は ``Assets/AGXUnity/AGXUnity/LicenseManager.cs`` です）。そのため、プレイヤーは **実行ファイルがあるフォルダをカレントディレクトリにして起動する** のが確実です。ユーザーのホームフォルダなど、任意の場所に置いたライセンスが見つかるとは限りません。

ライセンスファイルの扱い
--------------------------

- ライセンスが承認されるかどうか、有効期限、モジュール構成、再配布の条件は、すべてベンダーが発行した内容と契約条件に従います。アカウントの作成や評価版申請フォームの送信は、各自が公式ページから行ってください。
- ``.lfx`` 、 ``.lic`` 、 ``.rtlfx`` は、いずれも認証情報です。Git にコミットしないでください（リポジトリの ``.gitignore`` で除外してあります）。
- ハッカソンの終了後、配布されたライセンスをどう扱うか（削除、返却など）は、運営の指示に従ってください。
- ビルド済みプレイヤーを他の人に配布するときは、ライセンスファイルを同梱しないでください。受け取った人が、自分の PC でアクティベーションします。
